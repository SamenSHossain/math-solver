## Useful general facts
- From `Smooth U` and t ≥ 0: x ↦ U t x is ContDiff ℝ ∞ (compose the ContDiffOn with the smooth map x ↦ (t, x), which maps univ into Ici 0 ×ˢ univ; `ContDiffOn.comp`, then `contDiffOn_univ`). So `U t` is differentiable and its fderiv is continuous.
- From `Rapid U` with J = 0: for every (l, α) there is C with ‖mixed l α U t x‖ ≤ C for t ≥ 0. With l = 0, α = 0 this bounds U; with α = single i 1 it bounds dx i U. For t ≥ 0, fderiv (U t) x v = ∑ i, v i • dx i U t x (expand v in the basis `e i`, `EuclideanSpace.basisFun`), so ‖fderiv (U t) x‖ ≤ L := ∑ C_i, and U t is L-Lipschitz (`lipschitzWith_of_nnnorm_fderiv_le` / `Convex.norm_image_sub_le_of_norm_fderiv_le`).
- Partial derivatives within the half-space: for t ≥ 0, if HasFDerivWithinAt (uncurry U) D (Ici 0 ×ˢ univ) (t, x), then HasDerivWithinAt (fun s => U s x) (D (1, 0)) (Ici 0) t (compose with s ↦ (s, x)), so dt U t x = D (1, 0) by uniqueness (`uniqueDiffOn_Ici`, `UniqueDiffWithinAt.eq_deriv`/`fderivWithin` lemmas); similarly dx i U t x = D (0, e i). `ContDiffOn.fderivWithin` (needs `UniqueDiffOn`, e.g. `(uniqueDiffOn_Ici 0).prod uniqueDiffOn_univ`) makes (t,x) ↦ fderivWithin (uncurry U) (Ici 0 ×ˢ univ) (t,x) smooth on the half-space.

(b) EnergyClass: every spatial derivative of order ≤ 2 of U(t) vanishes outside the compact K (K is closed; U t ≡ 0 on the open set Kᶜ) and is continuous, so it lies in L² (`Continuous.memLp_of_hasCompactSupport` or `MemLp` via boundedness on a finite-measure set); the map t ↦ toLp is continuous on [0,T] because ‖F t − F s‖₂ ≤ √(vol K)·sup_K |F t − F s| and F is uniformly continuous on the compact [0,T] × K.
