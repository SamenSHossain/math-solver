Proof of Lemma 3.1 (as formalised in Solutions/Sol_OAI_SeymourSecondNeighborhood_Pruning_lemma_3_1.lean), assuming (A) konig and (B) matching_bound.

Setup. Let V := (X × X) ⊕ (X × X) be the vertex type used for both sides of Γ, Z := pointsZ arrow R C, H := pointsH arrow R C. The edge set E := gammaEdges arrow R C ⊆ V × V is the finset of all pairs satisfying the predicate EdgeP (conflict edges (inl l, inl c), left-cover edges (inl l, inr z), right-cover edges (inr z, inl c), exactly as in the hypothesis hM of (B)); lemma mem_gammaEdges gives e ∈ E ↔ EdgeP e. Two auxiliary characterisations: mem_pointsZ_iff: z ∈ Z ↔ ∃ l ∈ R, ∃ c ∈ C, Conflict l c ∧ z = (c.1, l.2); and mem_uncovered_iff (unfolding of the filter).

Step 1 (Kőnig). By (B), every matching M ⊆ E has |M| ≤ |Z| + |H|; hence (A) with k = |Z| + |H| yields a vertex cover KA, KB ⊆ V of E with |KA| + |KB| ≤ |Z| + |H|. We prune isolated vertices: KA' := KA.filter (∃ e ∈ E, e.1 = ·), KB' := KB.filter (∃ e ∈ E, e.2 = ·). KA', KB' still cover E (the covering edge is the witness) and |KA'| + |KB'| ≤ |Z| + |H|.

Step 2 (the pruned families). R' := R.filter (inl l ∉ KA'), C' := C.filter (inl c ∉ KB'). Clearly R' ⊆ R, C' ⊆ C. (i) No conflicts: if l ∈ R', c ∈ C' conflict, then (inl l, inl c) ∈ E is covered, so inl l ∈ KA' or inl c ∈ KB', contradicting the filters. (ii) Retention: lemma not_edge_fst_of_free shows that if l ∈ R conflicts with no c ∈ C then no edge of E has first endpoint inl l: a conflict edge at l would be a conflict; a left-cover edge (inl l, inr z) with z ∈ Z gives, by mem_pointsZ_iff, l₀ ∈ R, c₀ ∈ C in conflict with z = (c₀.1, l₀.2), and CoversL l z says z.2 = l.2 and arrow l.1 c₀.1, so arrow c₀.2 l.2 = arrow c₀.2 l₀.2 holds too and l conflicts with c₀, contradiction; a right-cover edge has first endpoint inr z ≠ inl l. Hence inl l ∉ KA' (as KA' only contains non-isolated vertices) and l ∈ R'. Symmetrically (not_edge_snd_of_free) for C'.

Step 3 (counting, lemma count_bound). Write DA := R.filter (inl l ∈ KA') = R \ R', DB := C.filter (inl c ∈ KB') = C \ C', ZA := Z.filter (inr z ∈ KA'), ZB := Z.filter (inr z ∈ KB'), U := uncovered arrow R C R' C'. Claim 1: |DA| + |ZA| ≤ |KA'|, since DA.image inl and ZA.image inr are disjoint subsets of KA' and inl, inr are injective (card_union_of_disjoint, card_image_of_injective); likewise |DB| + |ZB| ≤ |KB'|. Claim 2: Z ⊆ U ∪ ZA ∪ ZB: if z ∈ Z is not uncovered, either some l ∈ R' covers z, so the edge (inl l, inr z) ∈ E is covered, and inl l ∉ KA' forces inr z ∈ KB', i.e. z ∈ ZB; or some c ∈ C' covers z, so (inr z, inl c) ∈ E is covered and inl c ∉ KB' forces inr z ∈ KA', i.e. z ∈ ZA. Hence |Z| ≤ |U| + |ZA| + |ZB|. Combining with |KA'| + |KB'| ≤ |Z| + |H|: |R \ R'| + |C \ C'| = |DA| + |DB| ≤ |KA'| + |KB'| − |ZA| − |ZB| ≤ |Z| + |H| − |ZA| − |ZB| ≤ |H| + |U| (omega). This is the required bound (R \ R').card + (C \ C').card ≤ (pointsH arrow R C).card + (uncovered arrow R C R' C').card. No case split on the existence of conflicts is needed: the argument is uniform.

Proof of (A) Kőnig (Solutions/Sol_OAI_SeymourSecondNeighborhood_Pruning_konig.lean, CHECK OK), deficiency form of Hall's theorem. Let A₀ := E.image Prod.fst and N(S) := {b : ∃ (a,b) ∈ E, a ∈ S} (nbr). Choose S ⊆ A₀ maximising the deficiency |S| − |N(S)| (truncated subtraction), normalised so that |N(S)| ≤ |S| (if the maximiser has |N(S)| > |S| the maximum is 0 and S = ∅ works); let δ := |S| − |N(S)|. Augment the right side by δ dummy vertices: for a ∈ A₀ put t(a) := N({a}).disjSum (univ : Finset (Fin δ)) ⊆ B ⊕ Fin δ. Hall's condition holds: for a nonempty s ⊆ A₀ with image S' ⊆ A₀, N(S').disjSum univ ⊆ s.biUnion t, so |s| = |S'| ≤ |N(S')| + δ ≤ |s.biUnion t| by maximality of δ. Mathlib's Finset.all_card_le_biUnion_card_iff_exists_injective gives an injective f : A₀ → B ⊕ Fin δ with f a ∈ t a. Let M := E.filter (fun e => ∃ h : e.1 ∈ A₀, f ⟨e.1, h⟩ = inl e.2). M ⊆ E; Prod.fst is injective on M (f ⟨a,_⟩ determines b) and Prod.snd is injective on M (injectivity of f). Counting: univ.image f ⊆ M.image (inl ∘ snd) ∪ univ.image inr, so |A₀| = |univ.image f| ≤ |M| + δ, hence |A₀| ≤ k + δ by hypothesis hk. The cover is KA := A₀ \ S, KB := N(S): an edge (a,b) ∈ E has a ∈ A₀, and either a ∉ S (so a ∈ KA) or a ∈ S (so b ∈ N(S)); its size is |A₀| − |S| + |N(S)| = |A₀| − δ ≤ k.
